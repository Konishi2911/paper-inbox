# 設計判断

確定はユーザーが承認した方針、暫定は実装上の現在値、未確定は実装前の判断事項を表す。既存の詳細契約はリンク先を正とし、ここでは背景・採用理由・トレードオフを整理する。

| 判断 | 状態 | 背景・採用した設計 | 代替案・トレードオフ |
| --- | --- | --- | --- |
| ローカルファーストと軽量な境界 | 確定 | オフライン利用を基本にcore/portsと各アダプターを分離 | 全構造体の抽象化は学習・保守負担が大きいため避ける |
| 正規化SQL | 確定 | 書誌情報をSQL一本で扱い、履歴は不変スナップショット | 列+全体JSONは採用しない。テーブル・結合・移行は増える |
| 未入力と手動クリア | 確定 | 初回未入力は手動headなし、明示的クリアは保護 | 全項目に手動履歴を作ると補完まで承認が必要になる |
| 外部更新の承認と鮮度 | 確定 | 出典/レコード/更新日時/headで判定し手動値を保護 | 取得時刻優先は古い情報の再取得で上書きし得る |
| 候補の提示項目とID | 確定 | 未提示は変更なし、提示空値は削除提案。同ID/同内容は冪等 | 全書誌情報の単純置換は欠落と削除を区別できない |
| 関連付け・独立版・正規版 | 確定 | 同一性不明は保留。明示的関連付けと全項目承認。正規版切替は別承認 | 自動統合・一括置換は誤同定や手動値消失を起こす |
| 一括保存と競合 | 確定 | 文献全体と全headを照合し全コマンドを原子的に保存 | 項目ごとの独立保存より保守的に競合を拒否する |
| 引用キー | 確定 | 著者+年→代表語→2以降の番号。削除済みも予約。保存済みは自動変更しない | 文献更新連動の再生成は既存引用を壊す。ASCII化できない著者はAuthor |
| DOI/arXiv | 確定 | 接頭辞/公式URL/空白を除去、DOI小文字化、arXiv版保持。旧不正値は保持・警告 | 厳格読込のみでは旧DBが開けず、自動消去は情報を失う |
| 取得先と登録確認 | 確定 | DOI→Crossref、arXiv→公式API。新規はpreview確認、既存は候補へ | DataCite/任意URL/PDFは現段階の取得範囲に含めない |
| BibTeX | 確定 | UTF-8、保存済み対象、上書き確認、途中失敗で元ファイル保持 | 未保存内容や無確認上書きは採用しない |
| IDのDefault | 確定 | new()同様に新しいUUID | nilで未指定を表す方式は採用しない |
| UI構成と分割 | 確定 | 3ペイン、カードclick、親の遷移と子の表示を分離 | 1ファイル肥大化を段階解消。分割自体は目的にしない |
| 閲覧・編集 | 確定方針・実装途中 | 選択は閲覧、新規は編集、保存/取消は正常再読込で閲覧へ | bool edit-modeは暫定。Step 8後にEditor抽出、排他EnumはStep 13 |
| 幅とカード寸法 | 暫定 | 一覧380/最小260、詳細最小360、Splitter8、通常カード72を現在値とする | 全画面・言語・長文での適正値は実測で調整する |
| ライセンス | 確定 | 独自コードMIT OR Apache-2.0、Slint Royalty-freeと公式謝辞 | 依存コードの条件は別。[ライセンス説明](licenses.md)を参照 |

## これから判断する事項

- 複数選択: Ctrl/Shift/全選択の意図は採用するが、ページ・検索・sort変更時の範囲、非表示選択の維持、全選択の対象をStep 14前に確定する。
- ショートカット: 入力欄のコピー等を優先し、一覧focus時だけの操作を定める。
- FTS5・仮想化: 描画仮想化とDBページ取得を分け、日本語検索と性能を評価する。
- 添付: 内容ハッシュは方針。配置形式、DBとの障害整合性、孤立実体、検証範囲を設計する。
- 同期: 自動同期と双方保持は方針。transport、クラウド、端末間因果依存、欠落イベント、削除競合、タグ集合、圧縮/GCは未決定。
- UI設定: 保存形式・互換性・配置を現在のCLI Configと分けて検討する。
- Dark mode: 標準widgetとThemeの整合、OS設定追従、利用者設定の優先順を決める。

重要な仕様・非互換変更は選択肢とトレードオフを提示して判断を求める。現在のDB・生成APIへ過去案を無条件に適用しない。
